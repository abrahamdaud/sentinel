# Short Pitch

SENTINEL is a lightweight local security monitor for PowerShell and Termux. It runs offline, stays quiet, and helps you detect suspicious processes, suspicious files, and tampering without depending on any external server.

# Project Summary

SENTINEL is a local-only monitoring tool designed to help users stay aware of suspicious activity on their own device. It watches for suspicious processes, suspicious file patterns, file tampering, and remote-control software, while keeping output minimal and system overhead low.

The project is built for PowerShell and Termux environments, supports a lightweight TUI dashboard, and keeps all logs and state locally in the user’s home directory. It is meant to be quiet, stable, and non-intrusive while still providing practical security visibility.

# Release Message

SENTINEL v1.0.0 is now available as a lightweight local security monitor for PowerShell and Termux.

This release focuses on local-only monitoring, minimal output, and low-overhead operation. It includes suspicious process detection, suspicious file scanning, file tamper tracking, whitelist support, quiet stealth mode, and a lightweight terminal dashboard.

The project is designed to run without external servers or cloud services, keeping all monitoring, logging, and state local to the user environment.

Introducing SENTINEL — a lightweight local security monitor for PowerShell and Termux.

SENTINEL is designed to run offline, stay quiet, and help you monitor suspicious local activity without depending on external services. - whitelist support
